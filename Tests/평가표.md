## 재실행

저장소 루트에서 x64 Native Tools Command Prompt로 실행한다. 각 ID별 PASS 또는 FAIL을 출력하며 종료 코드는 실패 건수다.

~~~bat
cl /nologo /utf-8 /EHsc /std:c++17 Tests\GameWorldCases.cpp Server\GameWorld.cpp
GameWorldCases.exe
~~~

## 11월 15일 Room 연동 인계

11월 14일 준비 기준으로 팀 서버 커밋 0423529의 Common/protocol.h를 게임 클라이언트와 GameWorld 양쪽에 적용했다. 서버 테스트 18건이 통과했고 SceneManager.cpp와 StageScene.cpp가 공용 헤더로 컴파일됐다.

팀장 연동 순서

1. 서버 프로젝트에 Server/GameWorld.cpp를 컴파일 대상으로 추가하고 각 방이 별도의 GameWorld를 소유하게 한다.
2. 게임 시작 시 선택한 MAP_ID로 InitBoard를 호출하고 해당 방의 직전 갱신 시각을 시작 시각으로 설정한다.
3. 게임 중인 방에서 현재 시각과 직전 시각의 차이(ms)를 Advance에 전달하고 직전 시각을 갱신한다. 두 번째 인수는 이동 한 스텝을 실행할 함수다. 물풍선 StepBomb는 Advance 내부에서 호출한다.
4. 통합 확인 시 대기 중인 방의 이동 호출은 0회, 게임 시작 후 300ms 동안 이동은 25회, 물풍선은 6회여야 한다. 두 방의 시작 시각을 다르게 해서 각 방의 누적 시간이 독립적인지도 확인한다.

실제 Room을 거치는 항목의 판정은 머지 후 팀장 검증 예정이다.
